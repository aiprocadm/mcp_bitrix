# mcp_bitrix

MCP-сервер для Битрикс24.

MCP (Model Context Protocol) — это способ, которым ИИ-помощник (например, Claude)
получает «инструменты»: сервер описывает, что он умеет, а помощник вызывает эти
инструменты. Здесь такими инструментами будут операции Битрикс24 (CRM, задачи,
пользователи и т. д.) через REST API.

## Статус

Проект только создан. Кода пока нет.

## Структура (план)

- `src/` — код сервера
- `tests/` — тесты
- `.env.example` — какие настройки нужны (без секретов)
