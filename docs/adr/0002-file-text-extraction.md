# ADR 0002: извлечение текста из файлов портала (2026-10-07)

## Контекст

Помощнику нужно читать счета, выписки и акты, приложенные к сделкам и письмам (Диск, `FILES` дел CRM).
`DOWNLOAD_URL` из `disk.file.get` содержит авторизацию — у вебхука его код в пути (живой портал), поэтому ссылку нельзя
выдавать модели: файл скачивает сервер, наружу выходит только текст.

## Решение

- Скачивание — `BitrixClient.downloadFile` (единственное место сетевых вызовов): https или протокол портала, host из
  `BITRIX_ALLOWED_HOSTS`, без перенаправлений, общий лимитер, таймаут загрузок, предел `MAX_UPLOAD_BYTES` (заявленный и
  фактический размер потока). Адрес не логируется и не попадает в ошибки.
- Две зависимости (точные версии, MIT, без нативного кода и install-скриптов):
  - `unpdf@1.8.1` — текстовый слой PDF (сборка pdf.js для сервера). Сканы без текстового слоя не распознаются (OCR нет).
  - `fflate@0.8.3` — распаковка docx/xlsx в памяти; распаковываются только нужные части, каждая ≤ 20 МБ (защита от zip-бомб).
- Текстовые форматы: UTF-8, при ошибке — Windows-1251 (выгрузки 1С). HTML — существующий `htmlToText`.

## Отклонено

- Выдавать `DOWNLOAD_URL` модели — утечка кода вебхука.
- Тяжёлые парсеры (`pdf-parse` с устаревшим pdf.js, `xlsx`/SheetJS с CDN-дистрибуцией, `mammoth`) — больше кода
  и поверхность атаки; нужен только текст.
