**Противоречие с ТЗ §8** («при установке запрашиваются все, модули включаются тарифом»): Маркет требует минимальный
набор. Решение до подачи (владелец): либо публиковать полный набор с обоснованием в чате модератора (сервис —
универсальный доступ к модулям портала, каждый scope используется инструментами), либо выпустить «базовую» версию
(scope тарифа «Старт»: `crm`, `task`/`tasks`, `calendar`, `im`, `disk`, `user_brief`) — вызовы методов вне выданных scope
Bitrix24 отклоняет, сервис возвращает нормализованный `BITRIX_SCOPE_MISSING` (Б§14.5); модули вне тарифа скрыты по
тарифу (S09). Скрытие инструментов по фактически выданным scope портала — **не проверено**, при «базовой» версии
нужна отдельная задача.

## 4. Материалы карточки (черновики на русском; язык описания обязателен для региона)

**Название:** «MCP для Bitrix24 — подключение Claude и ChatGPT». Проверить, что название в лицензионном договоре
совпадает дословно (`checklist.md`).

**Краткое описание (1–2 предложения):** Подключите портал к Claude, ChatGPT и другим AI-ассистентам по протоколу
MCP: сотрудники работают с CRM, задачами, календарём и диском из чата со своими правами Bitrix24, а каждое изменение
подтверждают сами.

**Полное описание** (обязательные оговорки — `common-requirements.md` §1.B п.4–5):

- что делает: MCP-сервер для Bitrix24; 100+ инструментов (CRM, задачи, календарь, чаты, диск, базы знаний, каталог,
  заказы, лента, группы, телефония); чтение и изменение данных из Claude/ChatGPT;
- безопасность: каждый сотрудник — своим OAuth-токеном и своими правами; изменения — только после подтверждения
  плана в кабинете; удаления — только в тарифе «Бизнес»; данные хранятся в РФ;
- **нужен внешний платный сервис**: подписка на сервис «MCP для Bitrix24», 14 дней бесплатно, далее тарифы (цены из
  панели владельца `/owner/plans`, на дату подачи: Старт 990 ₽, Команда 2 990 ₽, Бизнес 7 990 ₽ в месяц) — со ссылкой
  на страницу тарифов;
- **нужен MCP-клиент** (Claude Desktop/Code, claude.ai, ChatGPT с поддержкой MCP) — отдельное ПО/подписка у его
  поставщика; модель обрабатывает данные у поставщика клиента (выбор — за клиентом);
- ограничения: только облачный Bitrix24; лимиты вызовов/записей по тарифу; тариф Bitrix24 и права пользователя
  ограничивают доступные данные; требуется установка администратором портала.

**Описание установки:** 1) Установите приложение (нужны права администратора портала). 2) Откройте приложение в
левом меню — это кабинет. 3) В разделе «Подключение» скопируйте адрес MCP-сервера и следуйте инструкции для своего
клиента. 4) Первый вызов из чата — например, «покажи мои задачи на сегодня». 5) Для изменений откройте ссылку из чата
и подтвердите план. Настройки: «Администрирование» — роли сотрудников, модули, лимиты, политика подтверждений.

**Поддержка:** email `{{SUPPORT_EMAIL}}`, форма `{{SUPPORT_URL}}`, часы `{{SUPPORT_HOURS}}`, срок ответа
`{{SUPPORT_RESPONSE}}` (обязательно указать график и срок — §1.B п.9).

**Ключевые слова (≤ 2000 символов, без брендов):** MCP, AI-ассистент, Claude, ChatGPT, искусственный интеллект,
чат-бот для CRM, автоматизация CRM, задачи из чата, календарь, Model Context Protocol. (Бренды AI-клиентов —
уточнить у модератора, считается ли это «search spam».)

**Категории (≤ 5):** уточнить по каталогу RU (например, «Интеграции», «Автоматизация»); не «Прочее».

**Иконка:** PNG/JPEG без прозрачности, квадрат 250–650 px, без логотипов 1С-Битрикс и чужих знаков (`§1.B п.10`) —
значит, **без логотипов Claude/ChatGPT**.

**Ссылки на документы** (открываются в браузере, html/pdf/txt, `§1.B п.12`): лицензионный договор —
`{{PUBLIC_BASE_URL}}/legal/offer` (из `docs/saas/legal/offer.md`), политика ПДн — `{{PUBLIC_BASE_URL}}/legal/privacy`
(из `privacy-policy.md`). Маршруты публикации документов в сервисе ещё не сделаны (S5/S10).

## 5. Скриншоты (≤ 1280×720, JPEG/PNG, в слайдере Bitrix24, реалистичные демо-данные без реальных контактов)

1. Кабинет в слайдере Bitrix24: «Начало» — статус подписки, использование, кнопка «Подключить к Claude/ChatGPT».
2. «Подключение»: адрес MCP и шаги для Claude Desktop (с картинкой настроек клиента).
3. Чат Claude: запрос «покажи сделки на этапе переговоров» и ответ с данными демо-портала.
4. Подтверждение записи: план операции «создать задачу» в кабинете, кнопки «Подтверждаю/Отклоняю».
5. «Администрирование»: роли сотрудников и модули.
6. «Подписка и оплата»: тарифы и использование.

Демо-данные: вымышленные компании, телефоны вида +7 900 000-00-00, домены example.ru (§2 «All demo data … must not
be real»). Пустые формы и тестовые пользователи не принимаются.

## 6. Тестовые данные для модератора

- Модератор проверяет на **своём** портале (`publication-requirements.md` §4: интеграция не должна работать только с
  одним заранее подготовленным порталом). Установка создаёт арендатора с пробным периодом 14 дней автоматически —
  отдельной учётной записи не нужно.
- В поле «Test Data» (не публикуется): инструкция подключения MCP-клиента (адрес `{{PUBLIC_BASE_URL}}/mcp`), что
  проверить (чтение сделок, создание задачи с подтверждением), контакт для связи. При необходимости владелец продлевает
  пробный период порталу модератора в панели `/owner` (действие «Продлить пробный период», журналируется).
- Если модератору нужен готовый MCP-клиент — **не проверено**, есть ли у модераторов доступ к Claude/ChatGPT; иметь
  запасной вариант (видео сценария, тестовый аккаунт клиента — по согласованию).
