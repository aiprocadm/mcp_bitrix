# Политика обработки персональных данных сервиса «MCP для Bitrix24»

> **ШАБЛОН. Требует проверки юристом до публикации. Не является юридической консультацией.**
> Подстановки `{{…}}` — см. [README](README.md). Редакция `{{VERSION}}` от `{{EFFECTIVE_DATE}}`.
> Документ публикуется в открытом доступе (ч. 2 ст. 18.1 152-ФЗ).

## 1. Общие положения

1.1. Политика определяет порядок обработки персональных данных оператором **{{SELLER_NAME}}** (ИНН {{SELLER_INN}},
адрес: {{SELLER_ADDRESS}}; далее — «Оператор») при работе сервиса «MCP для Bitrix24» по адресу {{SERVICE_URL}}
(далее — «Сервис»).

1.2. Политика разграничивает две роли Оператора:

- **Оператор** — для персональных данных пользователей Сервиса и представителей клиентов (раздел 3);
- **лицо, обрабатывающее данные по поручению** клиента, — для персональных данных, содержащихся на портале Bitrix24
  клиента (раздел 6). Для этих данных оператором является клиент; условия — в
  [Приложении 1 к оферте](offer.md#приложение-1-поручение-на-обработку-персональных-данных-ч-3-ст-6-152-фз).

1.3. Ответственный за организацию обработки персональных данных: {{DPO_NAME}}, {{DPO_EMAIL}}.

## 2. Принципы

Обработка ведётся законно и справедливо, только для заявленных целей, в минимально необходимом объёме, с
обеспечением точности данных и уничтожением по достижении целей (ст. 5 152-ФЗ). Базы данных, содержащие
персональные данные граждан РФ, размещаются на территории РФ (ч. 5 ст. 18 152-ФЗ): {{HOSTING_PROVIDER}},
{{HOSTING_CITY}}.

## 4. Передача третьим лицам

4.1. **ЮKassa** (ООО НКО «ЮМани») — для приёма платежей и формирования чеков: сумма, описание услуги, контакт для
чека, идентификатор способа оплаты. Данные банковской карты Пользователь вводит на странице ЮKassa; Оператор их не
получает и не хранит.

4.2. **Bitrix24** — Сервис обращается к порталу клиента от имени пользователя по OAuth; Оператор не передаёт в
Bitrix24 иных данных, кроме запросов пользователя.

4.3. **Провайдер хостинга** {{HOSTING_PROVIDER}} — размещение инфраструктуры в РФ.

4.4. **MCP-клиент пользователя** (Claude, ChatGPT и др.) — получает результаты вызовов, которые инициировал сам
пользователь. Выбор MCP-клиента делает пользователь/клиент; поставщик MCP-клиента может находиться за пределами РФ.
Оператор не передаёт данные поставщикам MCP-клиентов по собственной инициативе.

4.5. Государственным органам — только в случаях, предусмотренных законом.

## 5. Хранение и защита

5.1. Меры (ст. 18.1, 19 152-ФЗ): шифрование токенов и платёжных идентификаторов отдельным ключом каждого клиента;
главный ключ хранится отдельно от базы данных и резервных копий; изоляция данных клиентов средствами СУБД;
передача данных только по HTTPS; журнал действий сотрудников поддержки; доступ сотрудников Оператора к панели
управления — по паролю и одноразовому коду (двухфакторная аутентификация); у сотрудников нет инструмента просмотра
данных порталов клиентов; резервные копии шифруются и хранятся 14 дней.

5.2. Сроки хранения указаны в разделе 3; по их истечении данные уничтожаются, в том числе путём уничтожения ключа
шифрования данных клиента (криптоудаление) с последующим удалением записей.

## 6. Данные порталов клиентов (обработка по поручению)

6.1. Сервис обрабатывает данные портала только для исполнения вызовов пользователя: чтение и — после подтверждения
пользователем — изменение. Ответы Bitrix24 не сохраняются дольше, чем нужно для постраничного чтения (до 10 минут)
и для показа результата операции.

6.2. После окончания подписки или удаления приложения данные портала в Сервисе хранятся 30 дней для восстановления,
затем уничтожаются. Администратор портала может удалить их немедленно в кабинете.

## 7. Права субъектов

7.1. Субъект вправе получить сведения об обработке, потребовать уточнения, блокирования или уничтожения данных,
отозвать согласие (ст. 14, 21 152-ФЗ), обжаловать действия Оператора в Роскомнадзоре или суде.

7.2. Запросы направляются на {{DPO_EMAIL}} или почтой по адресу {{SELLER_ADDRESS}}. Оператор отвечает в срок,
установленный ст. 20 152-ФЗ (10 рабочих дней с возможностью продления на 5 рабочих дней с уведомлением).

7.3. Запросы в отношении данных, содержащихся на портале Bitrix24 клиента, Оператор передаёт клиенту как оператору
этих данных и содействует их исполнению.

## 8. Cookie

Кабинет и страницы входа используют только необходимые для работы cookie (сессия, защита от подделки запросов);
аналитических и рекламных cookie нет.

Уведомление Роскомнадзора об обработке персональных данных: {{RKN_NOTIFICATION}} (номер в реестре операторов).
