## План этапа S1 (срезы)

Ориентир; исполнитель уточняет по коду и отмечает здесь сделанное.

1. `DEPLOYMENT_MODE` (`single` по умолчанию) + проверки §15; `Platform` (логгер, конфиг, БД, ключи, аудит, общие лимиты) и `TenantScope` (auth-провайдер, клиент Bitrix24, capabilities, политики, хранилища) — `createApp` для single собирает один `TenantScope` как сейчас.
2. `tenantId` в ключах `operations`/`idempotency`/`cursors`/`audit`/`file_manifests`/`capabilities_cache` (миграция SQLite, значение `local` для single); `ToolContext.tenant`.
3. Диспетчер получает `TenantScope` на запрос (в single — единственный); реестр `TenantScope` с LRU и инвалидацией (интерфейс, реализация в памяти).
4. Тесты S01 на SQLite: два арендатора с разными mock-порталами в одном процессе — курсоры, операции, подтверждения, файлы не пересекаются; S14 — весь прежний набор зелёный.
