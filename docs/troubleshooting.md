# Если не работает (ТЗ §7.5)

| Симптом                                                            | Что проверить и сделать                                                                                                                                    |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `[CONFIG_INVALID] BITRIX_WEBHOOK_BASE_URL: ...`                    | Формат `https://портал/rest/<userId>/<код>/`, origin совпадает с `BITRIX_PORTAL_URL`, нет имени метода и `?`. Значение в сообщении не печатается намеренно |
| `[CONFIG_INVALID] READ_ONLY_MODE: допустимы только true или false` | В `.env` только `true`/`false`, без `yes`/`1`                                                                                                              |
| `Ключ шифрования не найден`                                        | `npm run setup`                                                                                                                                            |
| `Файл политики не найден`                                          | `npm run setup` создаст `policies/*.json` из примеров                                                                                                      |
| `doctor`: `profile FAIL BITRIX_AUTH_FAILED`                        | Вебхук удалён/пересоздан или URL скопирован с ошибкой. Проверьте в портале, пересоздайте, обновите `.env`                                                  |
| `BITRIX_SCOPE_MISSING`                                             | В настройках вебхука не отмечен нужный раздел (crm/task/im/disk/calendar). Добавьте только нужный, сохраните, снова `npm run doctor`                       |
| `BITRIX_ACCESS_DENIED`                                             | Права самого сотрудника на объект; проверьте под тем же пользователем в интерфейсе. Сервер это не обходит                                                  |
| `BITRIX_APP_CONTEXT_REQUIRED` (`WRONG_AUTH_TYPE`)                  | Метод требует локального приложения, вебхук не подходит; это отдельный этап (OAuth)                                                                        |
| `FEATURE_UNAVAILABLE`                                              | Метод/модуль недоступен на портале или тарифе; `bitrix_capabilities` покажет по методам                                                                    |
| `METHOD_NOT_ALLOWED` в `bitrix_rest_call`                          | Метод не в allowlist `policies/methods.json` или не читающий. Расширять allowlist — решение владельца                                                      |
| `BITRIX_RATE_LIMITED`                                              | Портал ограничил частоту; подождите, уменьшите объём запросов                                                                                              |
| Claude Code не видит инструменты                                   | `npm run build`, `claude mcp get bitrix24`, `npm run mcp:smoke -- --transport stdio`; абсолютные пути в команде add                                        |
| Нет пункта «Входящий вебхук»                                       | Права на интеграции/REST-доступ по тарифу. Через cookies браузера сервер не работает принципиально                                                         |
| Ответ `APPROVAL_REQUIRED`                                          | Запись ещё не выполнена; подтверждение человеком через CLI появится на этапе 6                                                                             |

Для обращения за помощью достаточно кода ошибки и `requestId` из ответа; секрет вебхука никому не отправляйте.
